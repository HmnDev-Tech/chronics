# Chronics 1.0.0-beta02

The second beta of Chronics — a local, offline notification archive for Android.

## What's new since 1.0.0-beta01

- **Material 3 Expressive UI redesign** — replaced repetitive uniform cards with expressive M3 `MaterialShapes` (`Sunny`, `SoftBurst`, `Cookie4Sided`–`Cookie12Sided`, `Clover4Leaf`, `Flower`, `Diamond`, `Gem`, `Arch`, `Fan`, `Pentagon`, `PuffyDiamond`, `Bun`), asymmetric shapes (`asymmetricExpressiveShape`), and connected segmented app picker lists (`segmentedItemShape`).
- **Expressive morphing & spring motion** — interactive polygon morphing (`MorphPolygonShape` / `rememberMorphPolygonShape`) on dock destinations, `ToggleButton` filter chips, timeline rail nodes, pin/action buttons, and settings icons; `ContinuousMorphBlob` hero/empty-state backdrops; wavy progress indicators (`CircularWavyProgressIndicator`, `LinearWavyProgressIndicator`); and `MotionScheme.expressive()` spatial transitions across screens.
- **Settings, theme & motion blur** — added system dynamic color toggle, scroll motion blur toggle, and a status poster header in Settings.
- **Sources & export reliability** — added native Shevery-API support alongside Shizuku, folder-name sanitization (`safeFolderName`), and i18n/export fixes.

## Install / Update

1. Download `app-release.apk` below.
2. Allow installs from your browser or file manager when Android asks.
3. Install the APK.

Requires Android 8.0 (API 26) or newer.

This build is signed with the same stable release key as `v1.0.0-beta01`, so it installs directly as an update over `1.0.0-beta01`.

## Privacy

Nothing leaves the device. The app declares no `INTERNET` permission and has no accounts, analytics, crash reporters or ads. Captured text lives in the app-private database and in `Downloads/Chronics` only.

## Feedback
