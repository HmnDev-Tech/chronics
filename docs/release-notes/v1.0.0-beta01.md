# Chronics 1.0.0-beta01

The first beta of Chronics — a local, offline notification archive for Android.

Chronics captures the full text of notifications the moment they arrive and
keeps a searchable copy in its own database and in `Downloads/Chronics`. A
message stays readable after it has been deleted from the chat or wiped from the
notification shade.

## Highlights

- **Full-text capture** — title, text, `bigText`, conversation, channel, group,
  priority, actions, attached photos and `MessagingStyle` messages with senders
  and timestamps.
- **Two more sources** — an optional accessibility service and Shizuku, which
  can also import whatever is currently in the shade.
- **Journal and search** — day-by-day timeline, pinning, archive, a detail screen
  with messages, attachments and raw extras.
- **Filters and masking** — app blocklist/allowlist, stop words, required words,
  duplicate merging, and optional masking of OTP codes, phone numbers, e-mail
  addresses and card numbers.
- **Exports** — one JSON and one TXT per entry, images under `media/`, and a full
  archive backup under `backup/`.
- **Pulse** — statistics by hour and day, top apps and capture sources.
- **Six languages** — English, Russian, Kazakh, Spanish, Chinese and Portuguese.
- **Adaptive sizing** — the layout scales from the real screen size and density,
  with a fine-tuning slider.

## Install

1. Download `app-release.apk` below.
2. Allow installs from your browser or file manager when Android asks.
3. Install the APK.

Requires Android 8.0 (API 26) or newer.

Every build is signed with the same stable key, so later releases install as an
update over this one. Builds published before the stable key was introduced used
a throwaway debug signature — if you installed one of those, uninstall it once.

## First run

1. Allow notifications on Android 13+.
2. Grant **notification access** — this is the main capture source.
3. Optionally enable the **accessibility service** and **Shizuku**.
4. Tap **Send test notification** and confirm the entry appears in the journal.

## Privacy

Nothing leaves the device. The app declares no `INTERNET` permission and has no
accounts, analytics, crash reporters or ads. Captured text lives in the
app-private database and in `Downloads/Chronics` only.

## Beta notes

- This is the first beta: the database schema and export format may still change
  before 1.0.0. Keep your own backup via **Settings → Storage → Export
  everything**.
- Deep capture through the accessibility service is experimental and slower than
  the default mode.
- Android may stop the accessibility service after a system update; re-enable it
  in system settings.
